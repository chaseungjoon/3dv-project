# 3DV Project

## Docs

| File | What it is |
| --- | --- |
| `SKILLMIMIC.md` | **Start here.** T09 baseline (SkillMimic-V2 on ParaHome cup / book / kettle): why, current status, how to run, where results go, troubleshooting |
| `SKILLMIMIC_NOTES.md` | Experiment rules and metrics, differences from the paper/upstream code, cup diagnosis and fix, upstream pitfalls, measurements, changed files, change log |
| `BASELINE_SKILLMIMIC.md`, `_2.md`, ... | Results, generated by `repos/skillmimic-v2/write_results.sh` (never overwritten; each run adds the next number). The first one: cup and book, upstream environment, 0% |
| `BASELINE_T09.md` | Earlier WristMimic baseline (kettle, 0%) |
| `skillmimic-v2.pdf`, `05_robotic_manipulation.pdf` | SkillMimic-V2 paper, course task sheet |

## Code

| Path | What it is |
| --- | --- |
| `repos/skillmimic-v2/` | SkillMimic-V2 + our scripts (`run_cup.sh`, `run_book.sh`, `run_kettle.sh`, `run_all.sh`, `write_results.sh`, `experiments/`) |
| `repos/t09-wristmimic/` | WristMimic (earlier T09 baseline), its own docs in `experiments/` |
