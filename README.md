# 3DV Project

## Layout

| Path | What it is |
| --- | --- |
| `repos/t09-wristmimic/` | WristMimic (humanoid manipulation, Isaac Gym). Our experiments are in `experiments/` |
| `repos/t10-crossformer/` | CrossFormer (cross-embodiment robot policy). Our experiments are in `experiments/` |
| `repos/skillmimic-v2/` | **T09 baseline.** SkillMimic-V2 (Isaac Gym) on ParaHome Drink Cup / Place Book / Place Kettle: `run_cup.sh`, `run_book.sh`, `run_kettle.sh`, `write_results.sh` |
| `repos/parahome/` | Full ParaHome dataset (7.7 GB) + clip audit, T09 viability check. Not needed by `skillmimic-v2` (it keeps its own copy of the 3 scenes it reads) |
| `repos/humanoidmimicgen/` | HumanoidMimicGen (MuJoCo, G1) Push Button with Diffusion Policy. T09 viability check |
| `isaacgym-env/` | Isaac Gym + PyTorch 2.4.1 built for RTX 50-series (sm_120) |
| `PROPOSAL_T09.md` | T09 plan: SkillMimic-V2 baseline on cup / book / kettle |
| `BASELINE_SKILLMIMIC.md` | SkillMimic-V2 baseline results (generated by `repos/skillmimic-v2/write_results.sh`) |
| `BASELINE_T09.md`, `BASELINE_T09_VARIETY.md` | Earlier WristMimic baseline (0%) and the follow-up that led to SkillMimic-V2 |

## Getting started

1. **Isaac Gym env** (needed for T09): see `isaacgym-env/README.md`. Isaac Gym itself and the torch wheel are not in git.
2. **T09, earlier WristMimic baseline**: `repos/t09-wristmimic/experiments/README.md`
3. **T10**: `repos/t10-crossformer/experiments/QUICKSTART.md`
4. **T09 baseline (SkillMimic-V2)**: `PROPOSAL_T09.md`, then `repos/skillmimic-v2/QUICKSTART.md`

Tested on Ubuntu 24.04 with an RTX 5070 (12 GB). Python envs are managed with `uv`.
